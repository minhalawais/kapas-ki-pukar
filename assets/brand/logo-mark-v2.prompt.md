# Kapas ki Pukaar Logo Mark V2

Text-free primary brand mark for compact mobile, web, and print use.

The mark combines a three-lobed cotton boll, a worker profile revealed through
negative space, and a single teal voice curve with a cotton-gold origin point.
The app name should remain live Urdu or English text outside the image.

Palette:

- Deep green: `#0B5D3B`
- Voice teal: `#2D9480`
- Cotton white: `#FFFFFF`
- Cotton gold: `#E5A62E`

Generated with the built-in image-generation workflow. The PNG uses an alpha
channel and intentionally excludes typography.
