# Change Request Template

Use this form for any material change after Phase 0 freeze.

Changes that **require** this form:

- new user role
- new primary portal page
- live backend / API / database
- live AI inference
- live SMS / OTP / push
- new critical grievance category
- new lifecycle state
- integration with Unified Workforce or other PUWF software
- material visual redesign
- real cross-device synchronisation
- MapLibre / GIS as a product surface
