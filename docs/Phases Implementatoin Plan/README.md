## How to Use

Each phase file includes:
- objectives;
- mandatory reference documents;
- step-by-step implementation instructions;
- relevant technical and styling file names;
- engineering rules;
- testing methods;
- phase-specific Definition of Done.

The team should not start a phase until dependencies from the prior phase have passed their exit criteria.
